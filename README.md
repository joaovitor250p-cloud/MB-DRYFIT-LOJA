# Links de acesso MB pelo GitHub Pages

Esta branch contém somente redirecionamentos para os sistemas existentes na Cloudflare. Não executa banco, login ou APIs no GitHub Pages, não copia dados e não altera os catálogos.

Ativação: Settings → Pages → Deploy from a branch → gh-pages → / (root) → Save. O repositório deve estar público para usar Pages no plano gratuito. Esta integração não possui permissão administrativa para alterar visibilidade ou configurar Pages.

Depois de uma implantação Pages bem-sucedida:
- https://joaovitor250p-cloud.github.io/MB-DRYFIT-LOJA/ abre o catálogo MB Dryfit.
- https://joaovitor250p-cloud.github.io/MB-DRYFIT-LOJA/acesso/ abre a escolha de dono/vendedor.
- https://joaovitor250p-cloud.github.io/MB-DRYFIT-LOJA/mb-dryfit/ abre o catálogo MB Dryfit.
- https://joaovitor250p-cloud.github.io/MB-DRYFIT-LOJA/mb-for-her/ abre o catálogo MB For Her.

O navegador passa para o endereço Cloudflare ao abrir. O sistema completo e seus dados continuam lá. A publicação desta branch não publica o código da branch de revisão nem faz merge do PR.
