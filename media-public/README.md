# Biblioteca de mídias gratuita — MB Dryfit + MB For Her

Este diretório contém apenas imagens públicas para os dois catálogos.
Nenhuma credencial, dado de cliente, pedido ou informação de estoque deve ser colocada aqui.

- `dryfit/`: imagens do catálogo masculino.
- `her/`: imagens do catálogo feminino.
- Use nomes curtos, únicos e sem dados pessoais.
- A publicação prepara uma versão WebP, com limite de 1600 px e compressão.
- Faça upload **somente** das fotos que podem ser vistas publicamente.
- Os arquivos originais permanecem no GitHub; o repositório cresce com o tempo.
- O domínio do Pages será definido depois da primeira publicação autorizada.

**Atenção:** Cloudflare Pages tem limites de implantação e GitHub tem limites práticos de tamanho. Não é armazenamento ilimitado; 5.000 imagens requerem monitoramento do tamanho do repositório. A biblioteca não implica contratação nem cobrança automática. Evite vídeos longos e pesados neste diretório.

O painel de envio direto ainda NÃO está conectado. Até existir integração autenticada e testada, subir fotos para esta pasta pelo GitHub e usar seus URLs publicados é um caminho manual provisório.
